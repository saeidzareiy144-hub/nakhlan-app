# پروژه اولیه اپلیکیشن نخلان

این بسته شامل کد رابط کاربری Flutter و **لوگوی اصلی ارسال‌شده توسط شما** است.

## امکانات نسخه اولیه
- رابط فارسی و راست‌چین با رنگ‌بندی هماهنگ با برند
- نمایش لوگوی نخلان در نوار بالای برنامه
- فهرست و جست‌وجوی محصولات نمونه
- سبد خرید نمایشی
- فرم نمونه سفارش و درخواست خرید عمده

## نکته مهم
این بسته **APK آماده نصب نیست**؛ سورس کد پروژه است. سفارش‌ها هنوز به سرور ارسال یا در پایگاه داده ذخیره نمی‌شوند، و قیمت‌ها/محصولات نمونه‌اند. برای استفاده واقعی باید اطلاعات محصولات و زیرساخت ثبت سفارش تکمیل شود.

## ساخت APK با Flutter
1. Flutter و Android Studio را روی کامپیوتر نصب کنید.
2. در ترمینال اجرا کنید: `flutter create nakhlan_app`
3. فایل `lib/main.dart` این بسته را جایگزین فایل هم‌نام در پروژه ساخته‌شده کنید.
4. پوشه `assets` این بسته را در ریشه پروژه کپی کنید.
5. در `pubspec.yaml`، زیر بخش `flutter:` این موارد را اضافه کنید (با فاصله‌گذاری دقیق):

```yaml
flutter:
  uses-material-design: true
  assets:
    - assets/nakhlan_logo.png
```

اگر `uses-material-design: true` از قبل وجود دارد، آن را تکرار نکنید؛ فقط بخش `assets` را اضافه کنید.

6. در پوشه پروژه اجرا کنید:

```bash
flutter pub get
flutter build apk --release
```

فایل خروجی معمولاً در مسیر زیر ساخته می‌شود:
`build/app/outputs/flutter-apk/app-release.apk`

ساخت نسخه iOS معمولاً به macOS و Xcode نیاز دارد.
