# ساخت APK نخلان از طریق فضای ابری

این پوشه یک پروژه Flutter است؛ APK از پیش ساخته‌شده نیست. برای ساخت APK بدون لپ‌تاپ:

1. در GitHub یک حساب بسازید و یک مخزن جدید با نام `nakhlan-app` ایجاد کنید.
2. از مرورگر گوشی، فایل‌های همین پوشه را در مخزن بارگذاری کنید؛ فایل‌های مخفی مانند `.github/workflows/build-apk.yml` نیز باید بارگذاری شوند.
3. در مخزن وارد زبانه **Actions** شوید، گردش‌کار **Build Nakhlan APK** را انتخاب کنید و **Run workflow** را بزنید.
4. پس از پایان موفق، در همان اجرای workflow پایین صفحه بخش **Artifacts**، فایل `nakhlan-release-apk` را دانلود کنید و ZIP آن را باز کنید تا `app-release.apk` به دست آید.

اگر مخزن عمومی است، کد و لوگو برای عموم قابل مشاهده خواهد بود؛ در صورت خصوصی‌بودن مخزن، تنظیمات حساب GitHub ممکن است محدودیت استفاده از Actions داشته باشد.

این نسخه فقط پروژه رابط کاربری اولیه است؛ برای ثبت واقعی سفارش‌ها، پنل مدیریت، ورود مشتری عمده و پرداخت آنلاین هنوز به بک‌اند و اتصال امن نیاز دارد.
